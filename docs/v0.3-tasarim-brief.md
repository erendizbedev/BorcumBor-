# v0.3 ortak tasarım özeti (3 ajan için)

Amaç: BorcumBorç'ün işlevi aynı kalır (iki kişi arası, internetsiz, karşılıklı onaylı borç defteri). Görünüş, menü, açılış ve sesler baştan, modern ve ilgi çekici yapılır. Önceki lacivert/periwinkle/nane görünüm beğenilmedi; benzerinden kaçın.

## Yön: "Mürekkep + Limon + Mor" (koyu, canlı, bento kartlı)
- Zemin: çok koyu mürekkep `#0B0B14`; kart `#14141F`; yükseltilmiş kart `#1C1C2B`; basılı `#26263A`.
- Ana eylem: elektrik moru `#7C5CFF` (gradyan `#9B7BFF` -> `#6A4BFF`), üstünde beyaz metin.
- Alacak / borç verdim / onay: limon-lime `#C6F432` (üstünde koyu `#10140A`).
- Borç / borç aldım / silme: sıcak pembe-mercan `#FF5C7A`.
- Bekliyor: kehribar `#FFB84D`. Bilgi: turkuaz `#3DD9EB`.
- Metin `#F5F5FA`, sönük metin `#A3A3BC`. Tüm metin/zemin çiftleri WCAG AA (4.5:1) olmalı.
- Köşeler büyük yuvarlak (kart 24px, düğme tam yuvarlak). Büyük, cesur tutar rakamları (Bricolage Grotesque), bento kart ızgarası, ince cam (blur) yüzeyler, yumuşak renkli parlamalar. Gölge/parlama sade tutulur; emoji yok, SVG ikon.
- Hareket: yalnızca transform + opacity, 150-350 ms, `prefers-reduced-motion` saygılı.
